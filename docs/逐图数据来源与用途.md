# 论文4 JPR v9 逐图数据来源与用途核查

核查范围为正文 8 张编号图、补充 17 张编号图和目录图，共 **26 张图**。图 1 按四个面板核查。逐张对照了最终图版、Word 内嵌图、图注、可定位的绘图代码和归档数据表。26 个 Word 嵌入图与独立 PNG 图件一致。

**实测数据**指公开人脑组织质谱的再分析。**统计模拟**指用于检验统计方法的生成数据或概率模型。**模拟演示**用于说明概念。**公开实验结构**指其他研究者使用冷冻电镜获得的结构坐标。图 1A 和 S16 使用同一套 310 个虚拟细胞，图 1B 和 S17 使用同一个公开结构条目。

## 复算入口

在仓库根目录运行 `python3 run.py` 后，`results/Figures.pdf` 提供带书签的 26 张 v9 图版，`results/Supporting_Data.zip` 提供对应的表 S1–S83、Data S1 和 Data S2。v10 的新增图、改版图和复算顺序见 [仓库说明](../README.md)。

图 1B 和 S17 的坐标可查阅 [PDB 6WM2 原始结构条目](https://www.rcsb.org/structure/6WM2)。
